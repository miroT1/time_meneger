# Личный тайм-менеджмент

Локальное приложение на Python + Streamlit. Данные хранятся в `data/time_tracking.xlsx`.

## Запуск в Windows
1. Установить Python с официального сайта и включить опцию добавления Python в PATH.
2. Дважды нажать `run.bat`.
3. При первом запуске скрипт создаст `.venv`, установит зависимости и откроет приложение в браузере.
4. Чтобы остановить приложение, вернуться в открывшееся окно терминала и нажать `Ctrl+C`.

Приложение не публикуется в интернете. Оно запускается локально на компьютере.

## Структура
- `app.py` — страницы и интерфейс приложения.
- `services/excel_storage.py` — чтение и запись Excel, создание ID и проверка связей.
- `data/time_tracking.xlsx` — файл с данными.
- `requirements.txt` — список библиотек.
- `run.bat` — быстрый запуск двойным щелчком.

На первом этапе реализованы проекты, задачи, ручной ввод сессий и история. Таймер будет добавлен отдельно.
